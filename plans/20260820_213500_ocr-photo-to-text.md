# OCR Photo to Text for Journal Entries

**Status:** completed

## The issue

Users currently have to manually type journal notes from physical documents, books, whiteboards, or receipts. They want to be able to snap a photo with the camera or pick an image from the gallery, extract the printed or handwritten text using OCR (Optical Character Recognition), and insert that text directly into their active journal entry.

All text recognition must happen 100% offline on the device to respect the app's zero-network, strict privacy architecture.

## The plan

### 1. Add Dependencies & Android Permissions
- Add `google_mlkit_text_recognition` for offline on-device OCR (Latin script recognition).
- Add `image_picker` to capture photos from the camera or pick from the gallery.
- Declare `android.permission.CAMERA` in `android/app/src/main/AndroidManifest.xml`.
- Update `docs/dependencies.md` documenting the packages and offline guarantees.

### 2. Service Layer: `OcrService`
- Create `OcrService` interface and `MlKitOcrService` implementation in `lib/features/entries/services/ocr_service.dart`.
- Processes local image files using Google ML Kit on-device recognizer.
- Never logs recognized text content (protecting user privacy via `AppLogger`).
- Cleanly disposes recognizer instances and removes transient files.
- Expose via Riverpod provider in `lib/features/entries/providers/ocr_providers.dart`.

### 3. Entry Editor Integration
- Add an OCR scan button to the editor toolbar in `lib/features/entries/presentation/editor/editor_toolbar.dart`.
- In `lib/features/entries/presentation/entry_editor_screen.dart`, provide an action bottom sheet to choose Camera or Gallery.
- Extract the text using `OcrService` and insert it into `QuillController` at the current cursor position.
- Display clear loading indicators and SnackBar messages on success, empty text, or error.

### 4. Localization
- Add new keys in `lib/l10n/app_en.arb` with `@description` entries:
  - `entryEditorScanText`
  - `entryEditorScanSourceCamera`
  - `entryEditorScanSourceGallery`
  - `entryEditorOcrScanning`
  - `entryEditorOcrNoTextFound`
  - `entryEditorOcrError`
- Run `flutter gen-l10n`.

### 5. Tests
- Add unit tests for `OcrService` with mock recognizer in `test/features/entries/services/ocr_service_test.dart`.
- Add widget tests for the OCR editor button and insertion flow in `test/features/entries/presentation/entry_editor_ocr_test.dart`.
- Verify `flutter analyze` and `flutter test` pass with 0 warnings.

# Replace Ritual Cards with 50 Sanathana Dharma Teaching Cards + User-Created Cards

**Status:** completed

---

## Problem

The current ritual deck has 18 generic reflection cards with Western philosophical quotes (Mark
Twain, Nietzsche, Emily Dickinson, etc.). The user wants **all** thought cards to carry
**Sanathana Dharma** teachings exclusively — sourced from Vedas, Upanishads, Bhagavad Gita,
Ramayana, Mahabharata, Yoga Sutras, Thirukkural, and the wisdom of Rishis and Acharyas.

Additionally, the user wants to be able to **create their own cards** from within the app.

---

## Scope

1. **Replace the 18 existing curated cards with 50 Sanathana Dharma cards** in
   `lib/features/ritual/domain/ritual_card.dart`.
2. **Update `RitualTheme` enum** to reflect Dharmic categories instead of generic ones.
3. **Add a database table for user-created cards** so custom cards persist across sessions in the
   encrypted database.
4. **Add a "Create Card" UI** accessible from the deck browser screen.
5. **Merge user-created and curated cards** in the deck, service, and providers.
6. **Add localization keys** for new UI text.
7. **Write a migration** for the new database table (schema version 9).

---

`quote` (the original teaching), `quoteAuthor` (scripture or sage).

### 2. Database — User-created cards table

#### [MODIFY] `app_database.dart` (`lib/core/database/`)

Add a new Drift table `UserRitualCards`:

```dart
class UserRitualCards extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get theme => text()();           // RitualTheme name
  TextColumn get title => text()();
  TextColumn get prompt => text()();
  TextColumn get quote => text()();
  TextColumn get quoteAuthor => text().nullable()();
  DateTimeColumn get createdAt => dateTime().withDefault(currentDateAndTime)();
  DateTimeColumn get updatedAt => dateTime().withDefault(currentDateAndTime)();
}
```

Add a DAO `UserRitualCardsDao` with CRUD operations.

Bump schema version from 8 to 9 with a migration that creates the table.

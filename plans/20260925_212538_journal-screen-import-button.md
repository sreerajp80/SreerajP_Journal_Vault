# Plan: Import button on the journal screen

**Status:** completed
**Change log:** `change_log/20260925_213105_journal-screen-import-button.md`

## Issue

Import is hard to find. Today the only way in is **Settings → Storage → Import Data**, and then
you have to pick the journal again from a list.

When you are inside a journal, the natural place to look is the journal screen itself. That screen
(`lib/app/app_journal_detail.dart`) has an **Export** icon in the top bar, but no **Import** icon.

## Fix

Add an **Import** icon button to the journal screen's top bar, next to the existing Export button.

- Icon: `Icons.file_open` (the same icon the import screen's "Select files" button uses).
- Key: `journal-import-button`.
- Tooltip: a new localized string, "Import into journal".
- It opens the existing `ImportScreen` for **this** journal (`journalId` and `journalTitle` from
  the open journal). No journal chooser is needed.
- **Shown only when the journal is open.** The same rule as Export: a password-locked journal
  must be unlocked first, so the button is hidden while the lock screen shows.
- **The list refreshes on return.** When you come back from the import screen, the journal
  screen reloads its entries, so the new entries show at once.

Nothing else changes. The Settings → Storage → Import Data route stays as it is.

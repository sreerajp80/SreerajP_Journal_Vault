# Plan: "Paste as Markdown" in the entry editor

**Status:** completed
**Change log:** `change_log/20260924_222720_markdown_paste.md`
**Note:** Approved 2026-09-24.

## Issue

When you paste Markdown text into an entry, it shows up as raw text: `#`, `##`, `**bold**`,
`| table |`, `[text](#link)` and list markers all stay as plain characters.

Why: on Android the clipboard only holds plain text. The Quill editor only turns a paste into
rich text when the clipboard holds HTML or a Markdown *file*. Plain text is pasted as-is.

The app already has a Markdown-to-Quill converter, but it lives inside the Import feature
(`lib/features/import/services/markdown_import_adapter.dart`) and only runs on imported `.md`
files. It also misses tables, links, nested lists, headings 4–6, check boxes, strike-through and
horizontal rules.

## Decision

The user chooses. The normal **Paste** stays exactly as it is (plain text, the default). A new
**Paste as Markdown** item sits right after it in the editor's long-press menu. There is no
guessing, so normal text is never changed by surprise.

## Fix

1. **Shared converter (services layer).** Move the Markdown parsing out of
   `MarkdownImportAdapter` into a new, pure Dart class
   `lib/features/entries/services/markdown_to_delta.dart` (no Flutter, no `BuildContext`).
   `MarkdownImportAdapter` calls it, so import behaviour stays the same or improves.
   Extend it to handle:
   - headings `#` to `######` (Quill header 1–6)
   - nested bullet / numbered lists by indent (Quill `indent` attribute)
   - task lists `- [ ]` / `- [x]` (Quill checked / unchecked list)
   - `~~strike~~`, `**bold**`, `*italic*`, `` `code` ``
   - links `[text](url)`: web links (`http`, `https`, `mailto`) keep the link. In-page anchors
     like `(#contents)` mean nothing inside a journal, so only the text is kept.
   - pipe tables `| a | b |` with a `|---|` line become the app's existing table block
     (`TableEmbed`); inline marks inside cells are removed (cells hold plain text).
   - `---` / `***` become a divider line (plain text `———`, since the editor has no divider
     block); fenced code blocks and `>` quotes as today.
2. **Menu item (presentation).** In `_buildSelectionContextMenu`
   (`lib/features/entries/presentation/entry_editor_actions_2.dart`), when the clipboard can be
   pasted, add **Paste as Markdown** directly after the standard Paste item. On tap it reads the
   clipboard's plain text, converts it, and inserts the result at the cursor (replacing any
   selected text). One paste = one undo step, so **Undo** removes it. Empty clipboard: nothing
   happens. The pasted text is never logged.
3. **Strings.** New key `actionPasteMarkdown` in all three ARB files, with an `@` description:
   - en: "Paste as Markdown"
   - ml: "മാർക്ക്ഡൗൺ ആയി ഒട്ടിക്കുക" — needs native-reader review
   - sa: "मार्कडाउन-रूपेण स्थापय" — needs native-reader review
   Then `flutter gen-l10n`.
4. **Tests.** `test/features/entries/services/markdown_to_delta_test.dart` covering each syntax
   above and the sample from the bug report. Keep
   `test/features/import/import_adapters_test.dart` and the l10n parity / label-length tests
   passing.

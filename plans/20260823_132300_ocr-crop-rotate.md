# Plan: Add crop & rotate step to the OCR image scanning flow

**Status:** completed

**Date:** 2026-08-23

## Problem

When scanning text from an image (OCR), the picked image goes directly to ML Kit
recognition with no way to remove unwanted elements or correct rotation. This reduces
OCR accuracy and forces users to pre-edit images externally.

## Solution

Add `image_cropper` (^12.2.1) — a wrapper around Android's uCrop library — to provide
a native crop-and-rotate UI between image selection and OCR processing.

## Files to change

### New files
- `lib/features/entries/services/image_edit_service.dart` — service wrapping `ImageCropper`
- `lib/features/entries/providers/image_edit_providers.dart` — Riverpod provider

### Modified files
- `pubspec.yaml` — add `image_cropper` dependency
- `android/app/src/main/AndroidManifest.xml` — add `UCropActivity`
- `lib/features/entries/presentation/entry_editor_screen.dart` — wire crop step into `_scanTextFromPhoto`
- `lib/l10n/app_en.arb` — add crop-related strings
- `docs/dependencies.md` — document the new dependency

# Plan: A6.4 Localisation (Extract UI strings and add Malayalam)

**Status:** completed

## Issue
While `flutter_localizations` is listed in `pubspec.yaml` and `l10n.yaml` exists, some UI strings (in Help screens, Features catalog, editor toolbar/embeds, and import views) are still hardcoded string literals. Additionally, `lib/l10n/` only contains `app_en.arb` without Malayalam (`app_ml.arb`) support. SreerajP apps follow an EN/ML bilingual standard where UI text follows the user's device language.

## Fix
1. Extract all remaining hardcoded UI strings into `lib/l10n/app_en.arb` with `@key` descriptions.
2. Update the affected UI widgets to use `AppLocalizations.of(context)`.
3. Create `lib/l10n/app_ml.arb` with full Malayalam translations for all ARB keys.
4. Run `flutter gen-l10n` to generate `app_localizations_ml.dart` and update `app_localizations.dart`.
5. Add test coverage for Malayalam localization in `test/l10n/`.
6. Run `flutter analyze` and `flutter test` to ensure everything passes with zero issues.

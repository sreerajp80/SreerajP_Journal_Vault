# C9: Ritual Mode — A Journal That Opens Like a Practice

**Status:** completed

## 1. Issue & Context
Journal apps frequently compete on utility and features, but rarely design the entry experience itself. Users often face "blank page syndrome" or open the app in a rushed, distracted state.

C9 introduces **Ritual Mode**: an optional guided opening practice designed to ground the user before writing.
It features:
1. A visual **breath timer** (e.g. 4-4-4-4 Box Breathing or 4-4 Calm breath) to calm the mind.
2. An **18-card curated reflection deck** (inspired by the `daily_rule_cards` family) with category themes, grounding quotes, and journaling prompts.
3. An **Anki-style spaced repetition engine** (Hard / Revision / Easy -> 1 / 3 / 7*level days) to resurface prompts and reflections intelligently.
4. Seamless 1-tap transition directly into `EntryEditorScreen` with today's date and the prompt seeded.
5. A dedicated deck browser, home screen quick entry, and settings toggle to optionally open Ritual Mode on app launch.

## 2. Proposed Changes

### Layer 1: Domain & Models
- `lib/features/ritual/domain/ritual_card.dart`
  - `RitualCard` definition (id, theme, title, prompt, quote, author, icon).
  - 18 curated reflection cards across themes: Clarity, Gratitude, Presence, Courage, Simplicity, Compassion, Wisdom, Resilience, Purpose.
- `lib/features/ritual/domain/spaced_repetition.dart`
  - `RepetitionRating` enum: `hard` (1 day), `revision` (3 days), `easy` (7 * level days).
  - `CardReviewState` model tracking review count, repetition level, next review date, and last reviewed timestamp.
  - Spaced repetition algorithm calculation functions.

### Layer 2: Services & State Management
- `lib/features/ritual/services/ritual_service.dart`
  - Loads 18 curated cards and manages per-card review states stored via `SharedPreferences`.
  - Determines today's featured prompt using the spaced repetition queue (due cards first, then rotating unreviewed cards).
  - Handles rating submissions to update card intervals.
  - Manages ritual settings (enable on startup, breath technique, breath duration).
- `lib/features/ritual/providers/ritual_providers.dart`
  - Riverpod providers for `RitualService`, `todayRitualPromptProvider`, `ritualDeckProvider`, and `ritualSettingsProvider`.

### Layer 3: Presentation
- `lib/features/ritual/presentation/ritual_screen.dart`
  - Multi-step serene flow:
    - Step 1: Animated visual breathing circle with phase guidance (Inhale, Hold, Exhale, Hold) and skip/continue controls.
    - Step 2: Reflection card viewer with theme badges, inspiring quotes, prompt questions, shuffle, and SRS rating buttons (Hard / Revision / Easy).
    - Step 3: Journal selection and "Begin Journaling" action, opening `EntryEditorScreen` seeded with the prompt.
- `lib/features/ritual/presentation/ritual_deck_screen.dart`
  - Deck browser allowing users to explore all 18 cards, filter by theme, and check SRS review schedules.
- `lib/features/ritual/presentation/widgets/breathing_orb_widget.dart`
  - Smooth custom animated breathing visual with pulsing glow and soothing timer.

### Layer 4: Integration
- `lib/app/app.dart`
  - Add "Start Daily Ritual" card / button in Home tab.
  - Add "Ritual Mode" tile in Settings tab.
- `lib/features/features_catalog/presentation/features_screen.dart`
  - Add C9 Ritual Mode entry to the journaling feature catalog.
- `lib/l10n/app_en.arb` & `lib/l10n/app_ml.arb`
  - Add localization strings for all ritual mode labels, prompts, themes, breathing phases, and SRS actions.
  - Regenerate localizations with `flutter gen-l10n`.

### Layer 5: Testing
- `test/features/ritual/services/ritual_service_test.dart`
  - Unit tests for the spaced repetition algorithm, deck loading, and prompt scheduling.
- `test/features/ritual/presentation/ritual_screen_test.dart`
  - Widget tests verifying the breathing timer, prompt card display, rating buttons, and editor navigation.

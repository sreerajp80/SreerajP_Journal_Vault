# Fix docs/features.md — correct stale claims and fill gaps

Implements: `plans/20260803_113244_fix-features-doc.md`

## What changed

Edited `docs/features.md` only. Five fixes:

1. **Opening paragraph**: added a short caveat that release builds are not yet signed with a
   real release key (fall back to the debug key), and that only attachments are encrypted at
   rest today — the SQLite database and FTS index are not. Pointed to
   `docs/architecture.md` section 21 for detail.

2. **Section 1 (Security, Privacy & Data Protection)**: added a "Disclosed Gaps" bullet listing
   the missing "Delete all data" action, the unencrypted database/FTS index, and the
   not-yet-versioned attachment crypto format.

3. **Section 3 (Media Attachments & Secure Viewers)**: added the shared viewer host screen
   (`attachment_viewer_screen.dart`) that owns the decrypted temp file and dispatches to the PDF
   / audio / archive viewer bodies. Also corrected the archive bullet — `.7z` is external
   hand-off only, not browsed in-app (only `.zip` is).

4. **Section 7 (Multi-Device Encrypted Sync Engine)**: added a leading note that the whole
   feature is built and tested but currently disabled — `AppFlavorConfig.enableSyncUi` is
   `false` because `SyncProtocol` has no transport, so no device-to-device sync can happen yet.

5. **Section 8, Permissions Management Center bullet**: corrected the permission list from
   "Storage, Microphone, Biometrics, Notifications" to what the code actually exposes —
   `AppPermissionId.attachmentImport` and `AppPermissionId.documentPicker`, both storage-related.

## Why

`docs/architecture.md` section 21 records a recent "last-mile integration pass" that deleted
files (`home_screen.dart`, `attachment_storage_location_service.dart`, others) and disabled the
sync UI at the flag level. `docs/features.md` had not been updated to match, so it overstated
what the Permissions Center covers, presented sync as a live feature, and did not disclose known
security gaps that are already tracked elsewhere in the docs.

## Verification

Checked each claim directly against source before editing, not just the earlier background
audit:
- `lib/features/permissions/domain/app_permission_models.dart` — confirmed `AppPermissionId`
  only has `attachmentImport` and `documentPicker`.
- `lib/core/config/app_flavor_config.dart` line 62 — confirmed `enableSyncUi => false` with the
  no-transport explanation.
- `docs/architecture.md` section 21 — confirmed the release-keystore gap, the unencrypted

No code files were changed — this was a documentation-only fix.

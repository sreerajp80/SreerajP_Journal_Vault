# Change log: Import button on the journal screen

**Plan:** `plans/20260925_212538_journal-screen-import-button.md`

## What changed

The journal screen now has an **Import** icon in its top bar, next to Export. Tapping it opens the
existing Import Files screen for that journal, so there is no need to go through Settings and pick
the journal again. After an import, going back reloads the entry list so the new entries show at
once.

Like Export, the button only shows once the journal is open. A password-locked journal must be
unlocked first.

The old route, **Settings → Storage → Import Data**, still works as before.

## Differences from the plan

- **Tests live in `test/journal_flow_test.dart`, not a new `test/app/` file.** The journal-screen
  tests and their shared helpers (`test/app_test_support.dart`) are already there. A new file
  under `test/app/` would have needed a relative import.
- **English tooltip shortened** from "Import into this journal" (24 characters) to "Import into
  journal" (19). `test/l10n/label_length_test.dart` limits tooltips to 20 characters. The plan was
  updated to match.

# Change log: Add crop & rotate step to OCR image scanning

**Date:** 2026-08-23
**Plan:** `plans/20260823_132300_ocr-crop-rotate.md`

## What changed

Added an intermediate crop-and-rotate step between image selection and OCR text
extraction. After a user picks or takes a photo for OCR scanning, the native uCrop
editor now opens so they can crop out unwanted elements and rotate tilted images
before recognition runs.

### New files

- `lib/features/entries/services/image_edit_service.dart` — abstract + concrete
  service wrapping `ImageCropper` (uCrop on Android). Follows the same pattern
  as `OcrService` for testability.
- `lib/features/entries/providers/image_edit_providers.dart` — Riverpod provider
  for the service.

### Modified files

- `pubspec.yaml` — added `image_cropper: ^12.2.1`.
- `android/app/src/main/AndroidManifest.xml` — added `UCropActivity` for the
  native cropper.
- `lib/features/entries/presentation/entry_editor_screen.dart` — wired the crop
  step into `_scanTextFromPhoto()`, between image picking and OCR. Cleans up both
  the original and cropped files in the finally block.
- `lib/l10n/app_en.arb` — added `entryEditorCropImageTitle` and
  `entryEditorCropImageError`.
- `docs/dependencies.md` — documented the new dependency.
- `test/features/entries/presentation/entry_editor_ocr_test.dart` — added
  `_FakeImageEditService` and overrode `imageEditServiceProvider` in all three
  test cases.

## Verification

- `flutter analyze` — zero issues.
- `flutter test` — 633 passing, 1 pre-existing failure (`mood_persistence_test`
  loading error, unrelated). All 3 OCR tests pass with the fake edit service.

# OCR Photo to Text for Journal Entries

**Plan:** `plans/20260820_213500_ocr-photo-to-text.md`

## Summary

Added on-device Optical Character Recognition (OCR) to allow users to take a photo or select an image from the gallery and insert the recognized text directly into their active journal entry.

## What changed

1. **Dependencies & Permissions**:
   - Added `google_mlkit_text_recognition` for 100% offline, on-device text recognition.
   - Added `image_picker` for photo capture via camera and selection from the gallery.
   - Added `CAMERA` permission and hardware feature declaration to `android/app/src/main/AndroidManifest.xml`.
   - Updated `docs/dependencies.md` documenting the packages and offline guarantees.

2. **OCR Service Layer**:
   - Created `OcrService` interface and `MlKitOcrService` in `lib/features/entries/services/ocr_service.dart`.
   - Exposed `ocrServiceProvider` in `lib/features/entries/providers/ocr_providers.dart`.
   - Guaranteed strict privacy by ensuring no recognized text content is logged.

3. **Entry Editor Integration**:
   - Added an OCR scan button to `EditorToolbar` (`lib/features/entries/presentation/editor/editor_toolbar.dart`).
   - Added an OCR scan button to the bottom action bar and implemented `_scanTextFromPhoto()` in `lib/features/entries/presentation/entry_editor_screen.dart`.
   - Inserts extracted text at the cursor position in the rich text editor and marks the entry dirty.
   - Safely cleans up temporary image files synchronously.

4. **Localization**:
   - Added user-facing strings and descriptions to `lib/l10n/app_en.arb` for scanning status, empty results, source selection, and error messages.
   - Regenerated `AppLocalizations`.

5. **Tests**:
   - Added unit tests in `test/features/entries/services/ocr_service_test.dart`.
   - Added widget tests in `test/features/entries/presentation/entry_editor_ocr_test.dart`.

# Change log — Translate the app name into Malayalam and Sanskrit

**Plan:** `plans/20260918_045400_localize-app-name.md`
**Status:** Implemented

## What changed

The app name is now translated, in both places that show it.

Before, `appName` in `assets/config/app_config.json` was a plain string, and `AppConfig`
typed it as a plain `String` on purpose, so the About heading was English in every
language. Separately, the ARB key `titleApp` — the window and task-switcher title — was
translated into Malayalam but was still the English name in Sanskrit.

Now `AppConfig.appName` is a `LocalizedText`, the config file holds one value per language,
and the Sanskrit `titleApp` is filled in with the same string.

### The names

| Language | Value |
|---|---|
| English | `Sreeraj P Journal Vault` |
| Malayalam | `ശ്രീരാജ്‌പി ജേണൽ വോൾട്ട്` |
| Sanskrit | `श्रीराज्पी दैनन्दिनीकोषः` |

The Malayalam is the string that was already in `app_ml.arb`, reused so nothing shifts for
Malayalam readers. The Sanskrit is new: the brand in Devanagari, with "Journal Vault" as
real Sanskrit — दैनन्दिनी (a daily journal) plus कोषः (a treasury or vault) — rather than
English written in Devanagari letters. It avoids the ऑ vowel sign, which is not a Sanskrit
sign.

## Notes on the code

- The old safety behaviour is kept. A wrong type such as `"appName": 42` still yields the
  fallback name, because `LocalizedText.fromJson` falls back on any value that is neither a
  string nor a map.
- A config file with a plain-string `appName` still works and resolves the same text in
  every language. There is now a test for exactly that, so an older config file cannot be
  broken by this change.
- Comparing two `LocalizedText` values directly does not work — the class defines no `==` —
  so the fallback assertions in the two config tests compare resolved strings instead.
- `AboutMetadata` still carries unresolved text only, so the application layer holds no UI
  string for a particular language. The presentation layer remains the only place that
  knows the active language.
- `titleApp` is already on the `allowedToRunLong` list in `test/l10n/label_length_test.dart`,
  so the longer Sanskrit name does not trip the label budget.

## Open point — English spelling is inconsistent

The English name is now spelled two different ways in the repository:

- `assets/config/app_config.json` → `Sreeraj P Journal Vault` (with a space)
- `lib/l10n/app_en.arb`, key `titleApp` → `SreerajP Journal Vault` (no space)

The About heading and the task-switcher title therefore disagree in English. The same
question applies to Malayalam, where the app name runs the two parts together
(`ശ്രീരാജ്‌പി`) while the author row keeps them apart (`ശ്രീരാജ് പി`).

This was left as found rather than guessed at, because picking one spelling is a branding
decision. Settling on the spaced form would also touch about a dozen other English strings
in `app_en.arb` that spell out the app name inside a sentence, and their Malayalam and
Sanskrit counterparts.

## 1. Overview

Implemented encrypted peer-to-peer Wi-Fi Sync for SreerajP Journal Vault, allowing two devices on the same local Wi-Fi or hotspot network to securely exchange database records and journal media attachments directly without requiring third-party cloud servers, accounts, or internet access.

## 2. Key Changes

### A. Dependencies & Permissions
- Added `qr_flutter: ^4.1.0` to render crisp pairing QR codes.
- Added `mobile_scanner: ^7.2.0` for instant camera-based QR scanning.
- Declared `android.permission.INTERNET` and `android.permission.ACCESS_NETWORK_STATE` in `android/app/src/main/AndroidManifest.xml` to allow standard local TCP socket binding and loopback communication.
- Updated `test/core/security/manifest_permission_guard_test.dart` to reflect local socket sync requirements.

### B. Networking & Wire Cryptography
- **Bounded Line Reader (`lib/features/sync/services/bounded_line_reader.dart`):** Implemented memory-safe socket line reader with strict caps (up to 150 MB for media payloads) and timeout protection to defend against DoS and memory exhaustion.
- **Wi-Fi Sync Crypto (`lib/features/sync/services/wifi_sync_crypto.dart`):**
  - High-entropy 16-character pairing code generation from a 31-character unambiguous alphabet.
  - PBKDF2-HMAC-SHA256 session key derivation with a random 16-byte salt transmitted over the wire.
  - AES-256-GCM symmetric payload sealing with random 12-byte nonces and 16-byte authentication tags.
  - Strict QR URI scheme (`sreerajp-journal-vault-sync://pair?v=1&h=...&p=...&c=...`).
- **Wi-Fi Transport (`lib/features/sync/services/wifi_sync_transport.dart`):**
  - `WifiSyncHost`: Binds an ephemeral local socket port, runs the challenge/response handshake, and provides a single-client lock.
  - `WifiSyncClient`: Connects to host via IP/port, solves cryptographic challenge, and streams encrypted payloads.
  - `localIpv4Addresses`: Discovers non-loopback local network IPv4 addresses.
- **Sync Protocol (`lib/features/sync/services/wifi_sync_protocol.dart`):** Implements `SyncProtocol` interface for `SyncEngine` over local sockets.
- **Attachment Cipher Integration (`lib/features/sync/services/sync_engine.dart`):** Integrated `BackupAttachmentCipher` to decrypt media attachments on sender, transmit binary bytes inside sealed sync records, and re-encrypt into the receiver's Keystore-managed attachment vault.

### C. State Management & Presentation
- **Providers (`lib/features/sync/providers/wifi_sync_providers.dart`):** Created `syncDeviceIdProvider`, `localIpv4ListProvider`, `WifiSyncHostNotifier`, and `WifiSyncClientNotifier`.
- **UI Screens (`lib/features/sync/presentation/`):**
  - `sync_landing_screen.dart`: Mode hub to choose Send vs Receive, displays detected Wi-Fi IP and links to Sync Health / Unresolved Conflicts.
  - `sync_host_screen.dart`: Displays QR pairing code, connection parameters, status chips, copy actions, and protected with `FLAG_SECURE`.
  - `sync_client_screen.dart`: Features camera QR scanner with `MobileScanner` and manual fallback entry tab with full input validation.
- **App Shell Integration (`lib/app/app.dart`):** Added Device-to-Device Sync tile to Settings.

### D. Localization
- Added full localized strings in `lib/l10n/app_en.arb` and `lib/l10n/app_ml.arb`.

# Change Log: C9 Ritual Mode — Guided Daily Practice

**Date:** 2026-08-24
**Plan:** `plans/20260824_111500_c9_ritual_mode.md`

## Summary of Changes

Implemented **Ritual Mode** in SreerajP Journal Vault to transform the entry experience into a mindful opening practice rather than a standard app launch:

1. **Curated 18-Card Reflection Deck (`lib/features/ritual/domain/ritual_card.dart`):**
   - Created an 18-card deck across 9 reflection themes (*Clarity, Gratitude, Presence, Courage, Simplicity, Compassion, Wisdom, Resilience, Purpose*).
   - Each card includes category metadata, prompt questions, grounding quotes, and author attributions.

2. **Spaced Repetition Engine (`lib/features/ritual/domain/spaced_repetition.dart`):**
   - Implemented an Anki-style spaced repetition algorithm (*Hard 1d / Revision 3d / Easy 7×level days*).
   - Manages per-card review states, interval scheduling, and automatic queue sorting.

3. **Ritual Service & State (`lib/features/ritual/services/ritual_service.dart`, `lib/features/ritual/providers/ritual_providers.dart`):**
   - Persists spaced repetition review state via `SharedPreferences`.
   - Manages breathing techniques (*Box Breathing 4-4-4-4*, *Relaxing 4-7-8*, *Calm 4-4*) and breath cycle preferences.
   - Schedules today's featured card based on review due status.

4. **Animated Breath Timer (`lib/features/ritual/presentation/widgets/breathing_orb_widget.dart`):**
   - Custom pulsating breathing visual with phase guidance (*Inhale, Hold, Exhale, Hold*) and timer countdown.

5. **Ritual Practice & Deck Browser Screens (`lib/features/ritual/presentation/`):**
   - `RitualScreen`: 3-step practice flow with breath timer, reflection card + SRS rating, and direct entry transition to `EntryEditorScreen`.
   - `RitualDeckScreen`: Full deck browser to inspect all 18 cards, filter by theme, check SRS intervals, and reset review levels.

6. **Shell & Catalog Integration:**
   - Added quick-access button to `_HomeTab` AppBar.
   - Added "Ritual Mode & Reflection" section card in `_SettingsTab`.
   - Added feature showcase entry in `FeaturesScreen`.
   - Added complete English and Malayalam localization strings.

7. **Verification & Tests:**

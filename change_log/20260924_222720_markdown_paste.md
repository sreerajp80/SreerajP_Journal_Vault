# Change log: "Paste as Markdown" in the entry editor

**Plan:** `plans/20260924_220102_markdown_paste.md`

## What changed

- **New menu item.** The entry editor's long-press menu now has **Paste as Markdown**, right
  after **Paste**. It shows only when Paste shows. It reads the clipboard text, turns the
  Markdown into formatted text, and inserts it at the cursor (replacing any selected text). One
  Undo removes it. Normal **Paste** is unchanged and stays the default.
- **Shared converter.** New `lib/features/entries/services/markdown_to_delta.dart`
  (`MarkdownToDelta`, pure Dart). It handles headings 1–6, bullet / numbered / task lists with
  nesting, quotes, fenced code, `---` dividers, pipe tables (as the editor's table block), and
  inline bold, italic, strike, code and links. Web links (`http`, `https`, `mailto`) keep their
  link; in-page anchors such as `#contents` keep only their text. Escaped characters (`\*`) stay
  literal, and `snake_case` words are not turned into italics.
- **Import uses it too.** `MarkdownImportAdapter` now calls `MarkdownToDelta` instead of its own
  parser, so imported `.md` files also get tables, links, nested lists and the rest. Plain text
  for search now comes from the converted content. The title from the first `#` heading has its
  inline marks removed. A small bug went away with the old parser: code block lines were
  followed by an extra empty line.
- **Strings.** New key `actionPasteMarkdown` in `app_en.arb`, `app_ml.arb` and `app_sa.arb`,
  regenerated with `flutter gen-l10n`.

## Limits

- Pasted content is never logged.
- The editor has no divider block, so `---` becomes a line of dashes (`———`).
- Table cells hold plain text, so bold or links inside a cell become plain text.
- The template editor still has only the normal Paste.
